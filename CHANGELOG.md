# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-28

### Добавлено
- Каталог: дерево категорий, карточка товара, скидки, полнотекстовый поиск с учётом морфологии и подсказки при опечатках.
- Отзывы с оценкой и модерацией, рейтинг товара.
- Корзина гостя и пользователя с объединением при входе.
- Оформление заказа: списание остатков в транзакции, промокоды, курьерская доставка, письма покупателю.
- Личный кабинет: история заказов, отмена нового заказа.
- Панель менеджера: смена статусов по допустимым переходам, история статусов, группа «Менеджеры магазина».
- REST API: каталог, корзина, заказы; аутентификация JWT.
- Docker: окружение разработки и прод-подобный стенд (gunicorn, nginx, HTTPS).
