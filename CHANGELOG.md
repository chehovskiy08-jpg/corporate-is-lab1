# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.1] — 2026-10-28

### Исправлено
- Телефон в заказе приводится к формату +7XXXXXXXXXX; заказы с некорректным номером больше не принимаются (форма и API).

## [1.0.0] — 2026-10-28

### Добавлено
- Каталог: дерево категорий, карточка товара, скидки, полнотекстовый поиск с учётом морфологии и подсказки при опечатках.
- Отзывы с оценкой и модерацией, рейтинг товара.
- Корзина гостя и пользователя с объединением при входе.
- Оформление заказа: списание остатков в транзакции, промокоды, курьерская доставка, письма покупателю.
- Личный кабинет: история заказов, отмена нового заказа.
- Панель менеджера: смена статусов по допустимым переходам, история статусов, группа «Менеджеры магазина».
- REST API: каталог, корзина, заказы; аутентификация JWT.
- Docker: окружение разработки и прод-подобный стенд (gunicorn, nginx, HTTPS).
## [1.2.0] — 2026-11-05

### Добавлено
- Фронтенд на React + TypeScript: каталог с фильтрами в адресе, карточка товара, вход и регистрация, корзина гостя и пользователя, оформление заказа, личный кабинет, раздел менеджера.
- API для SPA: регистрация, `/api/auth/me/`, перенос гостевой корзины `/api/cart/merge/`, `allowed_transitions` и `can_cancel` в заказе.
- Схема OpenAPI (`/api/schema/`, Swagger UI на `/api/docs/`).
- Образ `shop-nginx` со сборкой React на стенде.
- Тесты фронтенда (Vitest, MSW) и e2e (Playwright).

### Изменено
- На стенде nginx отдаёт SPA на всех адресах, кроме `/api/`, `/admin/`, `/healthz/`, `/static/`, `/media/`.

### Исправлено
- Оформление заказа через API без `delivery_method` возвращало 500 вместо 400.
